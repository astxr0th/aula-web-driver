# aula-web-driver

 script that makes the official AULA web driver (aulastar.com/web-drive, WebHID-based) usable on
 any Linux distro, for any Aula HID device.

 WebHID is only implemented by Chromium-based browsers (Chrome, Chromium, Brave, Edge,
 Vivaldi, Opera, Helium). Firefox and Safari have never implemented it.
